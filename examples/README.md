# 示例

| 路径 | 说明 |
|------|------|
| `cafe.ddproj` | 咖啡馆测试工程：3 场 8 镜、7 个机位、3 个场景物体（都引用立方体网格） |
| `scripts/cafe.md` | 完整测试剧本。稳定 ID，正文里预留 `> 景别` 等行（FND-20 之前只当正文） |
| `models/cube.obj` / `cube.glb` | 最小合法网格，用于导入与工程引用 |

启动：

```text
DirectorDesk.exe --project examples/cafe.ddproj
```

全流程可以按这个顺序点：

1. 编剧：看三场、改一行正文、保存
2. 置景：拖或选「桌子 / 杯子 / 立方体」，改位置
3. 掌机：镜头条切 8 镜，核对机位；可再套预设
4. 审片：分镜总览、刷新预览、导出镜头 / 导出总览
