# 分镜画布契约（Storyboard Canvas）

版本：1.0（P0）

## 一、定位

分镜画布是由 Markdown 剧本自动生成、类似思维导图的可视化分镜总览。它把“剧本结构、导演台镜头和导出结果”连接起来，不是自由绘图或通用节点编辑器。

核心流程：

1. 用户加载或编辑 Markdown 剧本；
2. 画布按 Scene/Shot 层级自动生成并布局；
3. 用户在 3D 导演台调整场景、相机和灯光；
4. 对应 Shot 卡片的缩略图自动刷新；
5. 用户点击卡片跳回对应相机继续调整；
6. 用户导出单镜头参考图或完整分镜总览 PNG。

## 二、数据来源与单向结构同步

- **剧本是结构的唯一真实来源**：Scene/Shot 的创建、删除、顺序、ID 和标题均来自 `modules/script-format.md`
- App 将 Script、Link、Camera 和导出状态转换为 `StoryboardSourceSnapshot`
- Storyboard 模块只消费不可变快照，不直接修改 Script、Scene、Camera 或 Link
- 剧本解析成功后，画布在同一主线程更新周期重建增量视图并自动布局
- 解析失败时保留最后一个有效画布，同时显示“剧本有错误，画布未更新”
- P0 不在画布中改标题、增删或重排镜头，避免双向同步破坏 Markdown

## 三、画布结构

```text
剧本根节点
├── Scene 卡片
│   ├── Shot 卡片
│   ├── Shot 卡片
│   └── ...
└── Scene 卡片
    └── ...
```

### Scene 卡片

- 场次标题、场次序号、镜头数量
- 可折叠/展开其 Shot
- 显示场次级诊断数量

### Shot 卡片

- 镜头标题和顺序号
- 最新缩略图或占位图
- 相机关联状态：`Unlinked` / `Linked`
- 预览状态：`Missing` / `Stale` / `Rendering` / `Ready` / `Failed`
- 导出状态：`NotExported` / `Exported`，以及最近导出时间
- 点击后选择该 Shot；若已关联相机，导演台切换到该相机

### 连线

- 只显示“剧本 → Scene → Shot”的父子关系
- 连线由结构自动生成，用户不能创建、删除或改接
- P0 不表达条件分支、并行剧情或任意节点关系

## 四、布局与导航

- 默认从左到右：剧本根 → Scene → Shot
- 同一 Scene 下的 Shot 严格遵循 Markdown 顺序
- 新增、删除、折叠或展开节点后自动重排，节点不得重叠
- 保持当前选中 Shot 尽量不跳出可视区域；必要时平滑聚焦
- 支持平移、滚轮缩放、适配全部、聚焦当前镜头
- 缩放范围和节点间距使用确定性常量，布局算法必须可单元测试
- P0 不支持自由拖动后保存位置；避免自动布局与手工布局冲突

## 五、导演台与缩略图同步

### 失效规则

- 已关联相机的 Transform、FOV 或预设变化：关联 Shot 标记 `Stale`
- 场景节点、模型、灯光变化：所有已关联 Shot 标记 `Stale`
- Shot 改绑相机：该 Shot 标记 `Stale`
- 仅修改剧本文字或画布缩放：不使缩略图失效

### 自动刷新规则

- 当前选中的已关联 Shot 在导演台停止连续操作后，使用短防抖自动刷新
- bgfx 渲染只能在主线程执行；不得从后台线程调用 Renderer
- 同一帧最多提交一个缩略图渲染任务，优先当前选中和当前可见卡片
- 全局变化只标记所有缩略图失效，按需惰性刷新，禁止一次阻塞渲染全部镜头
- 自动刷新失败时保留上一个缩略图并显示失败状态，可手动重试
- 缩略图不包含 UI、选框、操控器或编辑辅助线

缩略图缓存是可重建数据，不属于 `.ddproj` 的权威内容。缓存键至少包含 Project ID、Shot ID 和渲染修订号。

## 六、用户交互与 Command

Storyboard UI 只能发送 Command，至少包括：

- `SelectStoryboardShot`
- `FocusStoryboardSelection`
- `SetStoryboardSceneCollapsed`
- `RefreshStoryboardThumbnail`
- `ExportStoryboardBoard`

选择状态由 App 统一管理，并同步到：

- 剧本镜头列表；
- Storyboard 画布；
- Link 状态；
- 已关联的活动相机和 3D 导演台。

禁止 UI 直接调用 Script、Camera、Renderer 或 Export。

## 七、完整分镜总览导出

- 导出整个逻辑画布，而不是当前屏幕截图
- 输出 PNG，包含 Scene/Shot 卡片、父子连线、标题、缩略图和必要状态
- 排除面板边框、滚动条、悬停效果和编辑 UI
- 默认使用不透明背景，P0 不要求透明画布
- 保持 Markdown 的 Scene/Shot 顺序
- 导出时按所有 Scene 展开计算，必须包含全部 Shot，不受交互界面的折叠状态影响
- 输出按内容边界适配；任一边最长不超过 8192 px，超出时等比缩放并提示可能影响文字可读性
- 若存在 `Missing`/`Stale`/`Failed` 缩略图，导出前显示汇总并允许用户取消或继续
- 单镜头 1080p/2K 参考图导出仍由 Export 模块独立处理

画布导出必须使用与交互 UI 解耦的数据驱动绘制路径，不得通过截取应用窗口实现。

## 八、持久化

`.ddproj` 只保存：

- 布局方向（P0 固定/默认 `left-to-right`，为兼容保留字段）
- 折叠的 Scene ID

不保存：

- 自动计算的节点坐标
- 缩放和平移位置
- 缩略图像素
- 临时状态和悬停状态

## 九、性能目标

- 200 个 Shot 的结构变化后，布局与状态更新不应造成可感知的持续卡顿
- 只渲染可视范围内的卡片内容；布局可计算全部节点
- 缩略图纹理按可见性和最近使用情况管理，禁止无限增长
- 性能目标必须在 Windows 优先验证，并在 macOS 做回归

## 十、P0 明确不做

- 自由创建节点、自由连线、手绘、贴纸和批注
- 在画布内改写剧本结构或正文
- 自由拖动并持久化节点位置
- 条件分支、交互叙事、多人实时协作
- 视频缩略图或时间轴播放
- PDF、SVG 或可编辑思维导图格式导出

## 十一、最小测试集

- 从多 Scene/Shot 中文剧本生成正确树
- 新增、删除、重命名、重排剧本后动态同步
- 折叠 Scene、适配全部、聚焦选中 Shot
- 确定性布局、不重叠、严格保持剧本顺序
- 相机与场景变化后的缩略图失效范围
- 防抖和单帧单任务调度
- 无相机、缺失资产、渲染失败状态
- 200 个 Shot 的布局与可见区裁剪
- 完整画布 PNG 导出不含应用 UI
