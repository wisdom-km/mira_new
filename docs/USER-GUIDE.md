# 用户指南

DirectorDesk 把剧本变成可摆的 3D 分镜，再导出给后续 AI 生图/生视频使用。P0 **不接入**任何生成服务商，也不提供密钥设置。

## 第一次打开

```powershell
.\build\windows-debug\DirectorDesk.exe --project .\examples\cafe.ddproj
```

或启动后点左上 **导演台** 里的「打开示例工程」。

## 核心路径

1. **剧本**：右侧「剧本」打开 `.md`。语法见 `docs/dev-map/modules/script-format.md`。示例：`examples/scripts/cafe.md`
2. **资源**：左下「资源库」
   - **本地**：导入自己的 `.glb` / `.obj`
   - **在线**：浏览官方仓库并下载（需联网）。官方源固定，不能添加第三方地址
3. **摆镜头**：把模型拖进视口；用正视/侧面/过肩/俯视/特写；可添加多台相机
4. **关联**：选中一个 Shot，再点「关联到当前相机」
5. **分镜**：底部画布按剧本自动排布。剧本改结构后画布会重排，不能自由连线
6. **导出**：`文件` → 导出当前镜头 1080p/2K，或导出分镜总览 PNG。导出不含 UI 和地面格网

工程保存为 `.ddproj`（`文件` → 保存工程）。

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| Ctrl+N | 新建工程 |
| Ctrl+O | 打开工程 |
| Ctrl+S | 保存工程 |
| Ctrl+Shift+S | 工程另存为 |
| Ctrl+I | 导入模型 |
| Ctrl+E | 导出当前镜头 1080p |

视口：左键旋转，右键平移，滚轮缩放。分镜画布：右键平移，滚轮缩放。在文本框输入时快捷键不会触发。

完整列表也在菜单 **帮助**。

## 空状态含义

- 场景为空：还没有模型。从资源库拖入或导入文件
- 还没有场次：还没有有效剧本结构
- 打开剧本后会自动生成分镜画布
- 官方地址不可用：仍可使用上次成功缓存的清单和已下载模型

## 明确没有的功能

- 自定义在线源、软件内上传模型
- 骨骼动画、时间轴、自由画布连线
- 视频导出、真实 AI 生成按钮
